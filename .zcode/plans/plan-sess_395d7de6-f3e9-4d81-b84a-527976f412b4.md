# Wholesale Vegetable & Fruit B2B Ordering Platform

## What we're building
A mobile-first PWA where your client (admin) manages a catalog of vegetables (local + English/exotic) and fruits, vendors (hotels, resellers) get admin-created accounts, place orders during a daily order window (default 11 PM → 10 PM next day, editable by admin), and all orders are fulfilled together after the window closes. Payment collected on delivery.

## Stack
- **Next.js 15 (App Router, TypeScript)** on Vercel
- **MUI (Material UI) v6** as the component library — DataGrid for admin tables, Tabs/BottomNavigation for mobile nav, Steppers, Snackbars, etc. Themed to be clean and flat (light + dark mode)
- **Design guideline: Apple HIG principles via the apple-design skill** — I'll use it during implementation to keep the UI audit-quality: ≥44pt touch targets, 4.5:1 contrast, bottom tab navigation on mobile (no hamburger), scalable text, clear loading/error/empty states, sentence-case copy, light + dark appearance. I'll run a design review pass with it before delivery.
- **Prisma + Postgres (Supabase)** — free tier to start
- **Auth.js (NextAuth v5)** credentials auth, bcrypt-hashed passwords, role-based access (ADMIN / VENDOR)
- **Serwist** for PWA: manifest, installable, offline shell, mobile bottom-nav layout

## Data model
- **User** — role (ADMIN/VENDOR), business name, phone, address, password hash, active flag
- **Product** — name, category (Local Veg / English Veg / Fruits), unit (kg, crate, dozen, piece, box — per product), price per unit, image, active flag
- **OrderWindow setting** — start time, end time (spans overnight, e.g. 23:00 → 22:00 next day), timezone, editable by admin
- **Order + OrderItems** — tied to vendor + window date; items store quantity and price at order time; support admin-adjusted quantity per item with a note; status: PLACED → CONFIRMED → DELIVERED (or CANCELLED)
- Seed data: admin account, sample products with INR prices

## Order window engine
- Server-side logic computes open/closed from admin-configured times and timezone (default Asia/Kolkata)
- **Open**: vendors browse, add to cart, and can freely edit their order until the window closes
- **Closed**: ordering locked; vendors see when the next window opens and that delivery follows after close
- Admin can edit window times anytime; vendors get clear banner states (open / closing soon / closed)

## Vendor app (mobile-first, MUI BottomNavigation)
- Home with window status banner, category tabs, search
- Product cards with quantity steppers → cart → place order
- My Orders: history, status, totals, one-tap repeat order
- Profile

## Admin app (MUI DataGrid, responsive)
- Dashboard: today's window status, order/vendor counts, revenue
- Orders: per-window list, per-vendor detail, **edit any vendor order** (adjust quantities for stock shortfalls, add note shown to vendor)
- **Delivery manifest**: all orders consolidated and grouped by product for procurement/delivery, printable
- Products & categories CRUD, Vendors CRUD (create accounts, activate/deactivate, view history)
- Settings: window times, timezone, delivery info

## Assumptions (correct me if wrong)
- Currency **INR (₹)**, English UI, default timezone Asia/Kolkata — all configurable
- Product images optional (fallback to icon), admin can add image URLs
- No online payment — cash/UPI on delivery, tracked via DELIVERED status
